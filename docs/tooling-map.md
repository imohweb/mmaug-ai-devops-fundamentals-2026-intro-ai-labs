# AI Tooling Map

This page is a map, not a recommendation ranking. Choose tools based on the problem, constraints, team skills, security requirements and operating environment.

## Data and classical machine learning
- pandas — tabular data loading and manipulation
- scikit-learn — classical supervised/unsupervised ML, preprocessing and evaluation

## Deep learning
- PyTorch — neural-network development and research/production ecosystem
- TensorFlow / Keras — deep-learning development ecosystem

## Models and datasets
- Hugging Face — model/dataset ecosystem and tooling
- Ollama — convenient local model runtime for supported open models

## Generative AI application patterns
- direct prompting
- structured output
- embeddings and vector retrieval
- RAG
- tool/function calling
- agents
- evaluation and observability

## Microsoft ecosystem
Microsoft Foundry is Microsoft's platform for building, optimising and governing AI apps and agents. Product names and features change, so verify current Microsoft Learn documentation before a live demo.

Official documentation: https://learn.microsoft.com/en-us/azure/foundry/

## Interoperability
Model Context Protocol (MCP) is an open protocol used by AI applications to connect to tools and data sources through servers.

Official site: https://modelcontextprotocol.io/

## Security and governance references
- NIST AI Risk Management Framework: https://www.nist.gov/itl/ai-risk-management-framework
- OWASP GenAI Security Project: https://genai.owasp.org/

## Beginner principle
Do not start by asking “Which AI tool should I use?” Start with:

1. What problem are we solving?
2. What data is required?
3. What output or action is needed?
4. What is the consequence of being wrong?
5. What control and evidence make the system dependable?
