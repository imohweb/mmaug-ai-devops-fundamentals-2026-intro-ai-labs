# Beginner AI Concepts Glossary

**Artificial Intelligence (AI):** the broad field of building systems that perform tasks involving perception, prediction, language, reasoning, recommendation or action.

**Machine Learning (ML):** a way to build software that learns patterns from examples rather than receiving every rule explicitly.

**Deep Learning:** machine learning using neural networks with many layers, especially useful for complex data such as images, speech and language.

**Generative AI:** models designed to produce new content such as text, images, audio, video or code.

**Feature:** an input variable used by a model.

**Label / target:** the value a supervised model is trained to predict.

**Training:** the process of fitting model parameters using examples.

**Inference:** using a trained model to produce an output for new input.

**Classification:** predict a category.

**Regression:** predict a continuous number.

**Clustering:** group similar records without predefined target labels.

**Embedding:** a numeric vector representation of content that can capture useful relationships.

**Vector search:** retrieving stored items whose vectors are most similar to a query vector.

**RAG (Retrieval-Augmented Generation):** retrieving relevant external information and using it as context for an answer or generation task.

**Prompt:** instructions and context supplied to a generative model.

**Fine-tuning:** additional training that adapts a model's behaviour using examples. It is different from adding current/private knowledge at request time through retrieval.

**Tool call:** a structured request for external code or a service to perform an operation or return data.

**AI agent:** a system that uses a model to pursue a goal through steps such as planning, tool use, observation and feedback within defined boundaries.

**Structured output:** a response constrained to a known machine-readable shape such as JSON fields and types.

**Evaluation set:** repeatable inputs and expected properties used to compare system versions.

**Hallucination:** content generated without adequate factual support. A fluent answer is not proof of truth.

**Prompt injection:** malicious or conflicting input that attempts to make an AI system ignore trusted instructions or misuse tools/data.

**Human-in-the-loop:** a design where a person reviews, approves or handles specified decisions or exceptions.
