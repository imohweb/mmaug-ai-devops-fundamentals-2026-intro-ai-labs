# Dataset Sources

## Bundled datasets

The CSV files in `datasets/` are synthetic examples authored specifically for the MMAUG AI & DevOps Fundamentals Bootcamp 2026. They contain no real customer data and are distributed with this repository under its MIT licence.

## Optional public datasets for further practice

These are **not required** for the bootcamp labs. Always check the current licence and terms before reuse.

### scikit-learn datasets
https://scikit-learn.org/stable/datasets.html

Useful for small, well-documented learning examples without manually downloading a CSV.

### UCI Machine Learning Repository
https://archive.ics.uci.edu/

A long-running collection of datasets for ML education and research. Dataset licences and conditions vary.

### Kaggle datasets
https://www.kaggle.com/datasets

Large catalogue of community and organisational datasets. Licence, provenance and quality vary by dataset.

### Hugging Face Datasets
https://huggingface.co/datasets

Useful for text, image, audio and multimodal tasks. Check dataset cards, licences and data provenance.

## Dataset selection checklist

Before using a public dataset, ask:

1. Who created it?
2. What does each row represent?
3. Is the target reliable?
4. Is the population relevant to your intended use?
5. Are sensitive attributes present?
6. Are there licence or consent restrictions?
7. Could using the dataset cause harm or expose personal information?
