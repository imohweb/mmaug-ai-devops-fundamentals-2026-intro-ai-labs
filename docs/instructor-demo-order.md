examples are intentionally separate so participants still design their final
projects independently.

## Live-delivery advice

Before each command, tell learners what input they should see and what single idea the output demonstrates. After each command, explain the limitation. Avoid spending the session debugging package installation; ask participants to complete Lab 00 before the main hands-on sequence when possible.
