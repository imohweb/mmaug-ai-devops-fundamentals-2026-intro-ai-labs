# Presentation-to-Lab Map

This map connects the presentation to optional hands-on practice.

| Presentation topic | Participant resource |
|---|---|
| Machine learning | `labs/01-machine-learning-basics/` |
| Classification, regression and clustering | `labs/02-learning-tasks/` |
| Embeddings and vector similarity | `labs/03-embeddings/` |

## Assessment boundary

Labs 09 and 10 use neutral, fictional practice scenarios. They intentionally avoid the names, detailed requirements and solution patterns of the assessed capstone projects. Instructors should not present the guided case study as a preferred capstone architecture.

## Concept-only support

Topics such as AI history, ANN/CNN/RNN terminology, training versus inference, model choice and governance may not require a separate code lab. Use:

- `docs/ai-concepts-glossary.md`
- `docs/responsible-ai-checklist.md`
- `docs/tooling-map.md`
- `docs/reference-links.md`
