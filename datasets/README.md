# Synthetic Classroom Datasets

Every CSV in this folder is synthetic and was created for teaching. None contains a real person, customer, transaction, claim or operational record.

| File | Lab | Purpose |
|---|---|---|
| `service_requests.csv` | 01 | Demonstrate a binary-classification workflow using neutral IT service requests. |
| `customer_activity.csv` | 02 | Practise inspection, cleaning, classification, regression and clustering. |
| `mini_knowledge_base.csv` | 03–04 | Demonstrate similarity search and retrieval. |
| `equipment_maintenance_sample.csv` | 09 | Demonstrate guided triage, evidence and human escalation in a scenario unrelated to the capstones. |

## Why the data is small and messy

Small data makes every row visible and keeps execution fast. Some files deliberately contain missing values, duplicates or inconsistent labels so learners can practise cleaning. Model scores from these files are unstable and must not be used as business evidence.

## Safety

Do not replace these files with real personal, employment, financial, medical, customer or confidential operational data during the bootcamp.
