# Repository Guidance for Coding Agents

This repository is beginner-oriented educational material for the MMAUG AI & DevOps Fundamentals Bootcamp 2026.

When modifying the repository:

1. Preserve beginner readability.
2. Prefer standard Python and the existing dependencies.
3. Do not add external API keys or require a paid service for core labs.
4. Keep datasets synthetic unless an external dataset has a clear source and licence.
5. Never present toy metrics as production evidence.
6. Update the relevant README when code behaviour changes.
7. Run `pytest -q` and `python scripts/run_all_demos.py` before considering a change complete.
8. Keep security, privacy, evaluation and human oversight visible in examples.
