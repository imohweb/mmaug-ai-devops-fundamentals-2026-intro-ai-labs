# One-Page AI Solution Brief

## 1. Problem
What user/business problem are we solving? Write it without naming an AI product.

## 2. User and decision
Who uses the system? What decision or action does the output support?

## 3. Input data
What information is required? Where does it come from? Is any of it sensitive?

## 4. Smallest useful approach
Could rules or ordinary software solve it? If AI is justified, which capability is needed: classification, prediction, retrieval, generation, vision, speech, agent/tool use, or a combination?

## 5. Output
What exact output should the user/system receive? Free text, score, label, structured JSON, retrieved source, draft, action request?

## 6. Human oversight
What can happen automatically? What requires human review or approval?

## 7. Security and privacy controls
Identity, permissions, secrets, data minimisation, validation, content safety, prompt-injection controls, logging.

## 8. Evaluation
What test set, metric, acceptance threshold or review proves the system is useful and safe enough for the intended task?

## 9. Operations
How will you monitor failures, latency, cost, drift, security events and user feedback?

## 10. Fallback / rollback
What happens if the model, retrieval source or external tool is unavailable or produces unsafe/low-confidence output?
